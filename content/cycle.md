In this session the cycle is the path a metadata standard takes in Metaseed Hub: it is written as a profile, the profile is used to capture, validate, share and export metadata, and what users learn along the way goes into a revised profile, which starts the path again. The demo goes through the six steps once, and the no-laptop track maps participants' own workflows onto them.

{{< cycle >}}

## Why the last step matters

Standards change after datasets have been created with them. When a tool embeds its own copy of a standard, each change must be reimplemented in that tool, and existing datasets either break or silently diverge. In Metaseed Hub the profile is the single source for forms, validation and exports, and publishing a new version passes a version-bump gate. A dataset stays bound to the profile version it was created with.
