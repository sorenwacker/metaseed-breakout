## Abstract

> Metadata standards such as MIAPPE and ISA say what to record, but each tool builds its own version of them, and the standards change separately from the data built on them. In Metaseed Hub a data modeller writes a standard as a versioned, machine-readable profile and hands it to researchers. Entry forms, validation, and exports to repositories and FAIRDOM-SEEK are generated from that one profile, and datasets can be shared with colleagues. In this session we go through the cycle once: define a standard, capture metadata, validate, share, export, and revise the standard without breaking existing datasets. Participants then work hands-on as a researcher, data steward or developer. Bring a laptop if you want to try it, or come to discuss where metadata gets lost in your own workflow. No prior knowledge needed.

## What participants take away

After the session, participants:

- Know what it means to write a metadata standard as a machine-readable, versioned profile, and that entry forms, validation and exports can be generated from it.
- Have seen one standard go through a full round: defined, used to enter and check metadata, exported, and then changed without invalidating the existing dataset.
- Have tried it themselves in one role: corrected a dataset with errors (researcher), added their own fields to a repository standard (data steward), or created a dataset through the API or an AI agent (developer).
- Can judge where the tool would fit in their own workflow and where it does not yet, for example for clinical or health data.
- Can try it on their own standard or data in a follow-up pilot.

The session as a whole produces:

- A shared list of the points where metadata gets lost in participants' current workflows.
- Suggestions for which life science and health standards should be added next.
