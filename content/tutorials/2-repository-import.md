## You need

- A hub account.
- A public accession (examples to be chosen).

## Steps

1. Create an empty dataset with the matching profile.
2. Import the accession from the sidebar.
3. Inspect the entity tree and the graph view.
4. Validate and list what the repository record does not contain.
5. Export, or download the repository submission format where offered.
